# Gesture Photobooth (Laravel)

A gesture-controlled photobooth: hold up an open palm, it counts down, snaps
a photo, and saves it to a database (SQLite) via a Laravel backend.

## Important: GitHub alone won't run this

GitHub is just file storage / version control. GitHub Pages only serves
static HTML — it can't execute PHP or talk to a database. So the plan is:

1. Put this code in a GitHub repo (drag-and-drop, no git command line needed).
2. Deploy that repo to a PHP host that actually runs Laravel + SQLite —
   e.g. **Railway**, **Render**, or **DigitalOcean App Platform** all have a
   "deploy from GitHub repo" flow with free/cheap tiers.

## 1. Push this to GitHub by drag-and-drop

1. Go to github.com, click **New repository**, name it (e.g.
   `gesture-photobooth`), and create it.
2. On the repo page, click **Add file → Upload files**.
3. Drag the entire contents of this folder into the upload area (drag the
   *contents*, not the parent folder itself, so `composer.json` ends up at
   the repo root).
4. Commit the upload.

## 2. Get it running locally (optional but recommended first)

You'll need PHP 8.2+ and Composer installed on your machine.

```bash
composer install
cp .env.example .env
php artisan key:generate
touch database/database.sqlite
php artisan migrate
php artisan storage:link
php artisan serve
```

Then open http://localhost:8000 — grant camera access and you're set.

## 3. Deploy it live

Pick a host that deploys PHP apps from a GitHub repo, for example
**Railway** (railway.app):

1. Sign in with GitHub, "New Project" → "Deploy from GitHub repo" → pick
   this repo.
2. Set the build/start commands if asked:
   - Build: `composer install --no-dev --optimize-autoloader`
   - Start: `php artisan migrate --force && php artisan storage:link && php artisan serve --host=0.0.0.0 --port=$PORT`
3. Add environment variables from `.env.example` (generate `APP_KEY` with
   `php artisan key:generate --show` and paste it in).
4. Deploy. Railway gives you a public URL when it's done.

Render and DigitalOcean App Platform work the same way — connect the GitHub
repo, set the build/start commands above, add the env vars, deploy.

## What's inside

- `resources/views/booth.blade.php` — the camera UI + MediaPipe hand-gesture
  detection (open palm → 3s countdown → capture), posts each photo to the
  server.
- `app/Http/Controllers/PhotoController.php` — saves uploaded photos to
  `storage/app/public/photos` and a row in the `photos` table.
- `database/migrations/..._create_photos_table.php` — the `photos` table
  (id, path, timestamps).
- `app/Models/Photo.php` — Eloquent model, exposes a public `url`.
- SQLite is the database — it's just a file at `database/database.sqlite`,
  no separate database server to run.

## Notes

- This is a hand-written minimal Laravel 11 skeleton (not generated by
  `composer create-project`), so `vendor/` isn't included — `composer
  install` builds it from `composer.json`.
- If `composer install` ever complains about a missing skeleton file, the
  safest fallback is: run `composer create-project laravel/laravel fresh-app`
  locally, then copy `app/Models/Photo.php`,
  `app/Http/Controllers/PhotoController.php`,
  `database/migrations/..._create_photos_table.php`,
  `resources/views/booth.blade.php`, and the two routes in `routes/web.php`
  into that fresh project.
